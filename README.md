# Ejercicios Java: clases y objetos

Colección de ejercicios de programación orientada a objetos en Java, centrados en la creación y el uso de clases.

## Contenido
- Definición de clases con atributos y métodos
- Constructores y uso de `this`
- Creación de objetos e interacción entre ellos
- Encapsulación (getters y setters)
- ArrayList de objetos, herencia, métodos estáticos...
